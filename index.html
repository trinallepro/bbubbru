Séance 01 · 20 min

Quantificateurs
& ensembles

On part d'une phrase mathématique et on la fait descendre sur la droite réelle.

Énoncé

Q1 · Traduire ∃

E = { x ∈ ℝ ; ∃ n ∈ ℕ*, 1/n ≤ x ≤ 1 }

Cherchez si un seul entier n peut convenir à chaque x positif.

Solution. E = ]0, 1].

0 est exclu car 1/n > 0. Réciproquement, tout x > 0 convient en choisissant un entier n ≥ 1/x (et il faut aussi x ≤ 1).

Q2 · Traduire ∀

F = { x ∈ ℝ ; ∀ n ∈ ℕ*, 1/n ≤ x ≤ 1 }

Testez d'abord n = 1 : cette valeur suffit à serrer l'intervalle.

Solution. F = {1} = [1,1].

Pour n = 1, on obtient 1 ≤ x ≤ 1, donc x = 1. Et 1 vérifie bien l'inégalité pour tout n.

Q3 · Une inclusion qui inverse l'intuition

On pose Aₙ = [1/n, 1]. Montrer Aₙ ⊂ Aₙ₊₁.

Solution. Si x ∈ Aₙ, alors 1/(n+1) < 1/n ≤ x ≤ 1, donc x ∈ Aₙ₊₁.

Les intervalles sont croissants pour l'inclusion alors que la suite 1/n est décroissante : le sens est inversé car la borne gauche descend.

Q4 · Union finie, par récurrence

Montrer ⋃k=1n Aₖ = Aₙ.

Initialisation : pour n = 1, A₁ = A₁.

Hérédité : si la propriété est vraie au rang n, alors ⋃k≤n+1Aₖ = Aₙ ∪ Aₙ₊₁ = Aₙ₊₁ car Aₙ ⊂ Aₙ₊₁.

Ainsi, la propriété est vraie pour tout n. Au passage : E = ⋃Aₙ et F = ⋂Aₙ = A₁.
